# Core[Active-Level]
vhint.Core.Active-Level = Number of the place the player last travelled to with the map (14 beach, 19 bar, 25 mall...). Scenes that send you straight home do not change it.
# Core[Upcoming-Level]
vhint.Core.Upcoming-Level = The place a map or travel button has picked to go to next; the trip copies it into 'Active-Level' and then sets it back to 0.
# Core[Special-Fam-Check]
vhint.Core.Special-Fam-Check = True if the names the player chose contain mom, mother, dad, father or son; the game then also uses family words (Parents, Family, Sister) in other names.
# Core[Lock-Game]
vhint.Core.Lock-Game = True while a scene, talk or transition is running; the map, travel keys, room buttons and the Talk button do nothing until it is false again.
# Core[Start-Transfer]
vhint.Core.Start-Transfer = Set true by a map or travel button to start the trip to the place in 'Upcoming-Level'; the travel script sets it back to false when the move is done.
# Core[Cash]
vhint.Core.Cash = Money the player has (200 at the start, capped at 50,000,000). Shops and payments take from it; the nightly Starmaker payout, jobs and winnings add to it.
# Core[Daily-Income]
vhint.Core.Daily-Income = Starmaker income, never paid out or lowered: photos (+25), shoots and some scenes raise it. At 5000+ Frank, the insurance man, can visit the garage on Mondays.
# Core[Follower]
vhint.Core.Follower = Followers on the Starmaker page; photos, shoots and events add them. Sleeping on a Tuesday cuts them to 60% unless Celeste's quest is done.
# Core[Subscriber]
vhint.Core.Subscriber = Subscribers on the Starmaker page; each night's payout pays per subscriber. Sleeping on a Friday usually cuts them to 40% (50% with the Loyal Makers perk).
# Core[Debt]
vhint.Core.Debt = Josef's debt, 1,000,000 at the start. Set to 0 when it is paid: gifting Josef $1,000,000 at his office, Emma's sauna deal, or telling Josef to leave.
# Core[Auto-Skip]
vhint.Core.Auto-Skip = Auto-skip switch, flipped by a key press outside minigames. While true, lines in the empty dialogue box skip by themselves; the main box uses its speed button.
# Core[Cash-Before]
vhint.Core.Cash-Before = Cash when the register sound last played: a Cash change to at least this (not by idle income) plays the sound and updates it. Spending leaves it high.
# Core[Day]
vhint.Core.Day = Day of the week: 1 = Monday to 5 = Friday. Goes up by 1 each night and back to 1 after Friday; the skip button in your room jumps it ahead.
