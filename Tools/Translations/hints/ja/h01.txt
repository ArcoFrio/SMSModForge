vhint.Core.Upcoming-Level = マップや移動ボタンが次の行き先として選んだ場所。移動時に「Active-Level」へコピーされ、その後 0 に戻ります。
vhint.Core.Special-Fam-Check = プレイヤーが選んだ呼び名に mom、mother、dad、father、son が含まれていれば真。その場合、ゲームはほかの名前にも家族の語（Parents、Family、Sister）を使います。
vhint.Core.Lock-Game = シーン、会話、トランジションの実行中は真。偽に戻るまで、マップ、移動キー、部屋のボタン、Talk ボタンは何もしません。
vhint.Core.Start-Transfer = マップや移動ボタンが「Upcoming-Level」の場所への移動を始めるために真にします。移動が済むと、移動スクリプトが偽に戻します。
vhint.Core.Cash = プレイヤーの所持金（開始時 200、上限 50,000,000）。店や支払いで減り、Starmaker の毎晩の支払い、仕事、賞金で増えます。
vhint.Core.Daily-Income = Starmaker の収入。支払われることも下がることもありません。写真（+25）、撮影、一部のシーンで上がります。5000 以上で、保険屋の Frank が月曜日にガレージを訪れることがあります。
vhint.Core.Follower = Starmaker のページのフォロワー数。写真、撮影、イベントで増えます。Celeste のクエストを終えていなければ、火曜日に眠ると 60% に減ります。
vhint.Core.Subscriber = Starmaker のページの登録者数。毎晩の支払いは登録者 1 人あたりで払われます。金曜日に眠ると通常 40% に減ります（Loyal Makers パークがあれば 50%）。
vhint.Core.Debt = Josef の借金。開始時 1,000,000。返済されると 0 になります。オフィスで Josef に $1,000,000 を贈る、Emma とのサウナでの取引、Josef に出て行けと言う、のいずれかです。
vhint.Core.Auto-Skip = 自動スキップのスイッチ。ミニゲーム以外でキーを押すと切り替わります。真の間、空の会話ボックスのセリフは自動で進みます。メインのボックスは自身の速度ボタンを使います。
vhint.Core.Cash-Before = レジの音が最後に鳴ったときの所持金。Cash がこの値以上に変わると（放置収入によるものを除く）音が鳴り、これが更新されます。お金を使っても高いままです。
vhint.Core.Day = 曜日。1 = 月曜日～5 = 金曜日。毎晩 1 増え、金曜日の後は 1 に戻ります。あなたの部屋のスキップボタンで先に進みます。
