validation.quest.addedTaskTooDeep = 「{task}」はサブタスクのサブタスクです。ゲームのクエストは2階層で、追加するタスクも同じなので、追加されません。
validation.quest.addedUnderRemoved = 「{task}」はクエストから外されたタスクの下にあるので、プレイヤーには決して見えず、何もそれを待ちません。
validation.quest.addedUnderByAction = 「{task}」はアクションで完了するタスクの下にあります。そうしたタスクはサブタスクを決して始めないので、これも始まりません。
validation.quest.counterNeverCompleted = このタスクを完了させるものも数えるものもないので、クエストはここで止まります。完了条件を付けるか、Quest アクションで数えてください。
validation.quest.taskNeverCompleted = このタスクを完了させるものがないので、クエストはここで止まります。完了条件を付けるか、Quest アクションで完了させてください。
validation.quest.anyOneNeverCompleted = このタスクはサブタスクのどれか1つが完了すると完了しますが、どれも完了させるものがないので、クエストはここで止まります。
validation.quest.actionNoQuest = この Quest アクションはクエストを指していません。
validation.quest.conditionNoQuest = このクエスト条件はクエストを指していません。
validation.quest.unknownVanillaQuest = 「{quest}」は ModForge が知っているゲームのクエストではありません。ゲームでの名前とまったく同じつづりなら、それでも動きます。
validation.quest.actionUnknownQuest = クエストタブに「{quest}」というクエストはないので、この Quest アクションは何もしません。
validation.quest.conditionUnknownQuest = クエストタブに「{quest}」というクエストはないので、このクエスト条件は何もしません。
validation.quest.badOperation = 「{operation}」は Quest アクションにできることではありません。
validation.quest.actionNoTask = この Quest アクションにはタスクが必要ですが、指していません。
validation.quest.conditionNoTask = このクエスト条件にはタスクが必要ですが、指していません。
validation.quest.unknownTask = 「{quest}」にタスク「{task}」はありません。
validation.quest.notACounter = 「{task}」は数えないので、カウンターを設定してもプレイヤーに見えるものは何も変わらず、完了もしません。
validation.quest.counterFollowsVariable = 「{task}」は変数から数えるので、アクションが設定した値は上書きされます。
validation.quest.valueMissing = 「カウンターを設定」には数値が必要です。
validation.quest.valueNotNumber = 「{value}」は数値でも $変数 でもありません。
validation.quest.countAlwaysZero = 「{task}」は数えないので、数は常に 0 です。
validation.quest.badComparison = 「{comparison}」は比較ではありません。条件は決して満たされません。
validation.quest.conditionValueNotNumber = 「{value}」は数値でも $変数 でもありません。条件は決して満たされません。
validation.quest.badState = 「{state}」はクエストがなりうる状態ではありません。条件は決して満たされません。
validation.quest.counterNoVariable = このタスクは変数から数えますが、変数が選ばれていないので、数は決して動きません。
validation.quest.counterUnknownVanillaVariable = 「{name}」は ModForge が知っているゲームの変数ではありません。ゲームでの名前とまったく同じつづりなら、それでも動きます。
validation.quest.counterNotANumber = 「{name}」が持っているのは {kind} で、数値ではないので、数は決して動きません。
validation.quest.counterUnknownVariable = 「{name}」は変数タブで宣言されていないので、数は決して動きません。
