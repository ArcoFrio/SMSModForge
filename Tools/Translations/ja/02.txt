menu.savePackAs.keys = Ctrl+Shift+S
menu.exportPack.keys = Ctrl+E
menu.exportPack.tip = 保存して、このパックを最後にエクスポートした場所へそのままエクスポートします（初回は場所を聞きます）。
menu.exportPackAs.keys = Ctrl+Shift+E
menu.exportPackAs.tip = 保存して、選んだ .smspack ファイルにエクスポートします。そのパスがワンクリックでのエクスポート先になります。
menu.publishPack.tip = このパックをリリースとしてまとめます。検証し、バージョンを進め、プレイヤーがゲームのフォルダーにそのまま展開できる zip を書き出します。
menu.duplicateItem.keys = Ctrl+D
menu.duplicateItem.tip = 今のタブのリストで選んだ項目を複製します（新しいキーで）。
menu.copyItem.keys = Ctrl+C
menu.copyItem.tip = 選んだリストの項目をコピーします。このエディターのセッションで開いているどのパックにも貼り付けられます。リストにフォーカスがあるときは Ctrl+C でも使えます。
menu.pasteItem.keys = Ctrl+V
menu.pasteItem.tip = コピーした同じ種類の項目を今のタブのリストに貼り付けます。リストにフォーカスがあるときは Ctrl+V でも使えます。
menu.renameItem.tip = 選んだリストの項目のキーの名前を変えます（リストにフォーカスがあるときは F2 か F12）。
menu.deleteItem.keys = Del
menu.deleteItem.tip = 選んだリストの項目を削除します（リストにフォーカスがあるときは Del）。
menu.themes.tip = エディターの配色を変えます。選択はセッションをまたいで記憶されます。
menu.confirmChangesSave.tip = modpack.json を書き込む前に、保存で変わるものをすべて一覧にして確認を求めます。選択はセッションをまたいで記憶されます。
menu.spellCheckNodeText.tip = 行が書かれている言語（パック自身の言語、または編集中の言語）で、Windows 自身のスペルチェッカーでつづりの誤りに下線を引きます。ノードのテキスト欄とノードの一覧の両方に表示されるので、ざっと見ても誤りがわかります。Windows に辞書のない言語には下線がまったく引かれません。辞書は Windows の言語の設定で追加できます。テキスト欄で波線を右クリックすると、候補の表示、このセッションでの無視、Windows の辞書への単語の追加（Edge や Office と同じリスト）ができます。オフにすると、非常に長い会話でノードの一覧のスクロールも軽くなります。選択はセッションをまたいで記憶されます。
menu.versionPackAutomatically.tip = 保存のたびにパックのバージョンを進めます。パックに何かが増えたらマイナーを、既存のものが変わったらパッチを上げます。メジャー番号が自動で変わることはありません。それは「新しい版のパック」を意味し、決めるのはあなたです。オフにすると、バージョンは入力したときだけ変わります。
menu.warnWhenVersionGoes.tip = ディスク上のものより低いバージョンを保存する前に確認します。下げるのはほぼ必ず打ち間違いで、新しいリリースがプレイヤーの持つコピーより古く見えてしまいます。
menu.warnAboutLargeExports.tip = 150 MB または 1600 ファイルを超えるパックのフォルダーをエクスポートする前に確認します。パックとは関係ないものが入り込んでいないか確かめるためです。チェックを外すと、確認画面で設定したパックごとの「今後は警告しない」も解除されます。
menu.addPackNamesToDictionary.tip = このパックが作ったキャラクター、アクター、場所、NPC の名前をまとめて Windows の辞書に追加し、つづりの誤りとして印が付かないようにします。先に一覧を表示します。
menu.checkUpdatesStart.tip = エディターの起動時に一度だけ、新しいバージョンが公開されていないかリリースのページに問い合わせます。オフにすると問い合わせはまったくしません。選択はセッションをまたいで記憶されます。
menu.installUpdatesWithoutAsking.tip = 変更内容のウィンドウを飛ばします。見つかった更新は自動でダウンロードしてインストールされ、何かを開く代わりにウィンドウ上部の1行で知らせます。仕上げにエディターは再起動し、保存していないパックがあれば先に確認します。
